# ProofKeeping

> 清掃記録を、稼働の証跡に。

清掃現場の記録から「その部屋が実際に使われたか」を毎日突き合わせ、
記録上の稼働との差異を検出する Web プラットフォーム。

株式会社ステック（stek.ai）

---

## リポジトリ構成

```
CLAUDE.md              Claude Code 用の常時ルール（200 行以内）
.claude/rules/         詳細ルール 5 ファイル
docs/
  PK-SPEC-P0.md 〜 P7.md   フェーズ別仕様書 8 冊
  tasks/                   実行可能タスク 132 件
  PROGRESS.md              進捗管理
  OPEN_QUESTIONS.md        未解決事項
  DECISIONS.md             技術判断の記録
  EXECUTION-GUIDE.md       Claude Code での進め方
```

## 開発の始め方

1. `docs/EXECUTION-GUIDE.md` を読む
2. `docs/tasks/P0-01.md` から着手する
3. 1 task = 1 PR = 1 セッション

## 絶対に譲らない 5 つのこと

1. 清掃員に差異レポートを見せない
2. 発行済み帳票と証跡を削除できる実装にしない
3. 宿泊者の個人情報を保存しない
4. 「不正」という言葉を使わない
5. P3 のデータ蓄積 4 週間を飛ばさない

詳細は `CLAUDE.md` と `.claude/rules/` を参照。
