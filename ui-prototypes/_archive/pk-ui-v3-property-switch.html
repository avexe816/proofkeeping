1️⃣ 施設切替の設計

PC — 上部バー左に施設セレクタを常設。ドロップダウン内に各施設の 清掃済/作業中/未清掃 をミニバッジで表示し、どこへ行くべきか一目で判断できるようにした。オーナー・ORG_ADMIN・AUDITOR には「全社サマリー」を最上部に置き、これを既定画面とする。PROPERTY_MANAGER 以下は割当施設のみ表示され、全社項目は出ない。

スマホ — 清掃員に「切替」という概念を持たせない。1日で複数施設を回る場合は施設ごとにグループ化した単一リストを表示し、施設間に移動時間ブロックを挟む。担当が4施設以上の場合のみ、起動時に施設選択画面を出す。

2️⃣ 客室マスタ — 2方式

🅰 自主維護🅱 PMS連携
実装時期P0（1か月目）P6（10か月目）
外部依存なしPMS の API が必要
登録方法範囲一括登録 / CSVPMS から取得 → 差分承認
自動上書き—しない（差分提示のみ）
清掃専用の部屋自由に追加可ProofKeeping 側で追加
料金標準機能¥2,000〜5,000/施設・月
推奨全顧客の既定大型・部屋数変動が多い顧客
10〜80室の中小施設は API を持たない PMS を使っていることが多い。「PMS を繋がないと使えない」設計にすると導入自体が止まるため、方式Aを主戦場、方式Bをオプションとする。
