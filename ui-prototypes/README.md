# UI プロトタイプ

ProofKeeping の全55画面のUIプロトタイプです。各HTMLファイルは単体で開けます（外部依存なし）。

## 構成

| 対象 | 画面数 | ファイル | 備考 |
|---|---|---|---|
| 清掃員モバイル | 16 | `mobile/pk-01〜16-*.html` | 1画面1ファイル |
| ホテル・オーナー PC | 12 | `owner/pkown-v3-A〜D.html` | v3レイアウト改修済み・1ファイル3画面 |
| 清掃会社 PC | 12 | `ops/pkops-A〜C.html` | 1ファイル3〜4画面 |
| プラットフォーム運営 PC | 12 | `platform/pkplat-A〜D.html` | 1ファイル3画面 |
| 参照実装 | 2 | `pk-v3-layout-standard.html` / `pk-plan-compare-base-pro.html` | |

## 読む順序

1. `pk-v3-layout-standard.html` — v3レイアウト標準の参照実装。管理PC全画面がこの構造に従う
2. `mobile/` — 清掃員モバイル16画面。記録の入力源であり、全体の前提
3. `ops/` — 清掃会社PC。雇用主側の管理画面
4. `owner/` — オーナーPC。発注元向け。清掃員の氏名を表示しない設計
5. `platform/` — プラットフォーム運営PC。P4エンジン管理・監査
6. `pk-plan-compare-base-pro.html` — Base / Pro の機能差の比較

## 各ファイルの見方

- 画面下部に**設計判断のメモ**を付けています（暗色のカード群）
- 上部の LANG / STATE / VIEW ボタンは**プロトタイプ用の操作**です。製品には含みません
- 管理PCの言語切替は右上のユーザーメニュー内にあります
- ダークモードは右上の「ダーク」ボタンで切り替わります
