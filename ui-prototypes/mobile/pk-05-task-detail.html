🎯 この画面の設計意図

3段タイマーで状況を一目に。目安・経過・チェック進捗を横並びにした。清掃員は「あと何分か」ではなく「あとどれだけ作業が残っているか」で判断するため、時間と進捗を同時に見せる。

超過表示に赤を使わない。経過が目安を超えたらオレンジ、1.5倍でグレーにする。赤は「異常」「失敗」を意味してしまい、丁寧に作業している人を追い詰める。

チェックリストと写真は別画面へ。1画面に詰め込むとスクロールが長くなり、手袋での操作が難しくなる。ここは「今どこまで進んだか」を見る場所に絞る。

完了ボタンは条件を満たすまで押せない。グレー表示＋残件数を併記し、何が足りないかを明示する。押してからエラーを出すより早く気づける。

⏱ タイマーの色分け

経過表示意図
目安以内通常色問題なし
目安を超過オレンジ気づかせるが責めない
目安の1.5倍グレー超過の意味を薄める
2倍以上グレー（変えない）長時間でも責めない
❗ 赤は使いません。清掃時間が長くなる理由は、汚れがひどい・設備不具合・新人研修中など、本人の責任でないことが多いためです。時間で人を評価しない方針を UI で徹底します。

🔀 状態遷移

  • ⏸ 中断 → 理由選択（リネン待ち・休憩・他業務・その他）
  • 🚫 入室不可 → 理由選択（DND・在室・施錠・その他）
  • ✓ 完了 → 必須チェック全完了＋写真必須項目クリアで有効化
  • 中断・再開はすべて taskTimeLog に記録される
  • 実作業時間は中断を除いた合計で算出
💡 中断を3回挟んでも actualMinutes が正しく計算されることを、テストの必須項目にしています（PK-SPEC-P1 §14.1）。
