📐 v3 レイアウト標準（確定）

施設セレクタとユーザー領域の配置をv3の形で標準化します。以降のすべての管理画面はこの構造に従います。

┌──────────────────────────────────────────────────────────┐ │ TOPBAR h=58px bg=--brandTop │ │ ┌─ブランド─┐ ┌施設セレクタ┐ ┌通知┐┌ユーザー┐ │ │ │ 214px │ │ ▼ 展開404px│ … │ 🔔 ││ 田 田中▼│ │ │ └──────────┘ └────────────┘ └────┘└──────────┘ │ ├──────────┬───────────────────────────────────────────────┤ │ SIDEBAR │ PAGE HEADER（画面名 + 操作） │ │ 214px ├───────────────────────────────────────────────┤ │ nav only │ CONTENT │ └──────────┴───────────────────────────────────────────────┘
💡 ブランド幅とサイドバー幅をどちらも214pxに揃えています。施設セレクタの左端がサイドバーの右端と一致し、縦のラインが通ります。

🏨 施設セレクタを topbar に置く理由

以前はサイドバー内に置いていましたが、v3で topbar へ移しました。

論点v3の判断
施設はナビゲーション項目かいいえ。全画面に効くスコープ
影響範囲サイドバーの全項目＋コンテンツ
正しい階層サイドバーより上位

施設を切り替えるとサイドバーの内容も含めて全部が変わります。サイドバーの中に置くと、自分自身を切り替える項目がナビの一部に見えてしまい、階層が逆転します。

❗ 位置だけでなくドロップダウン内に各施設の状態を要約表示することも標準に含めます。完了 / 作業中 / 要対応の3数字を並べ、切り替える前に「どの施設が要対応か」が分かる状態にします。

📊 全社サマリーを既定にする

オーナーが複数施設を持つ場合、ドロップダウン最上段に「全社サマリー」を置き、ログイン直後の既定表示にします。

  • 単一施設のオーナーには表示しない（項目が1つだけになるため）
  • 複数施設のオーナーには既定で全社サマリーを開く
  • 全社表示中は施設名の見出しで区切る
  • 全社表示中であることを画面内で明示する
💡 上部の施設セレクタをクリックして「全社サマリー」を選ぶと、客室ボードが3施設の横断表示に切り替わります。KPIの数字も合算されます。

👤 ユーザー領域の内容

右上のユーザーメニューには役割と閲覧範囲をバッジで表示します。これは v3 標準の必須項目です。

役割バッジ表記
オーナーオーナー · 自施設のみ
運営管理者運営管理者 · 全施設
現場責任者現場責任者 · 担当施設

自分がどの権限で何を見ているかを常に確認できる状態にします。複数の役割を兼ねる担当者が誤読するのを防ぎます。

🔔 通知バッジの位置

通知はユーザーメニューの左隣に固定します。サイドバー内の各項目にもバッジは出ますが、未読の総数は topbar 右に集約します。

  • 件数は重要度 HIGH・MEDIUM の合計のみ
  • LOW は既定で通知に含めない（11 施設設定の方針）
  • 99件を超えたら「99+」と表示
  • 0件のときはバッジを出さない

✅ v3レイアウト 確定事項

  • topbar 高さ 58px、背景は --brandTop（サイドバーより濃い）
  • ブランド幅・サイドバー幅ともに 214px で縦ラインを揃える
  • 施設セレクタは topbar 左、ブランドの右隣に固定
  • ドロップダウン幅 404px。各施設の状態を3数字で要約
  • 複数施設の場合は最上段に「全社サマリー」を置き既定とする
  • 通知とユーザーは topbar 右端に配置
  • ユーザーメニューに役割＋閲覧範囲のバッジを必ず入れる
  • サイドバーはナビゲーションのみ。施設・ユーザーを含めない
