## 印刷する 2 枚について

`cleaner-guide.html` と `inspector-guide.html` は、ブラウザで開いて
そのまま印刷してください。**用紙は A4・余白なし・拡大縮小 100%** です。

- `cleaner-guide.html` は 2 ページ出ます（**1 ページ目が日本語、2 ページ目が英語**）。
  1 言語あたり A4 1 枚に収める決まりです（§7.1 MUST）。
- **項目を足すと 2 枚目にこぼれます。** 足すときは何かを削ってください。
  1 枚に収まっているかは `tests/docs/customerDocs.spec.ts` が押さえています。

## 書くときの決まり

顧客向けの文書は、**画面と同じ語彙**で書きます。使ってよい語と避ける語の
一覧は `.claude/rules/ui-writing.md` §2 にあります。**ここに写経しません。**

この規則は、画面だけでなく**文書にも当てはめています**（docs/DECISIONS.md #174）。
避ける語を「〜ではありません」という否定形で持ち込むと、その一文だけが
検索に引っかかり、抜粋されたときに逆の意味で読まれます。否定形でも使いません。

CI は `tests/docs/customerDocs.spec.ts` でこのディレクトリ全体を走査します。
走査の対象は**読者が目にする本文**で、HTML のコメントは除きます。
