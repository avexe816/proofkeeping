## やること
- 上部バーに施設セレクタを常設（全画面共通）
- ドロップダウンに各施設の状態サマリー（清掃済/作業中/未清掃）をミニバッジ表示
- 全社ビューを持つロールにのみ「全社サマリー」を表示
- `GET /api/v1/properties/summary` を新設（rollup テーブルから取得・60秒KVキャッシュ）
- `POST /api/v1/auth/switch-property` に `"ALL"` を受け付ける（権限チェック付き）
- URL に propertyId を含める（`/app/p/{propertyId}/board` / `/app/org/dashboard`）
