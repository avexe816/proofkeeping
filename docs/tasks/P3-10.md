## 作業ログ

2026-08-13 実装。`/app/settings/baseline`（`routes/app/baselineSettings.tsx`）。

- 客室タイプ・人数・種別のセレクタは**実データのある組み合わせだけ**を出す。
  全組み合わせを並べると観察 0 件の行が大量に出る。
- 信頼性 `×` の行は `pk-row--muted` でグレー表示し、注記を常時出す（§6.2）。
  **隠さない**（貯まっていない組み合わせが見えないと P3-13 を判断できない）。
- p90 の上書きは理由必須。空なら保存せず画面に返す。解除ボタンは
  上書き中の行にだけ出る。**どちらも監査ログ**（security.md §6）。
- 算出値（`p90Qty`）は書き換えず `manualOverride` に持つ。読む側は
  `manualOverride ?? p90Qty`。

API も §7 のとおり用意した（`routes/api/v1/baselines.ts`）。
`GET /baselines` / `PATCH /baselines/:id/override` / `POST /baselines/recompute`。
**画面は W-20 と同じくリポジトリを直に呼ぶ**（DECISIONS #099）。

権限は `baseline.read`（OWNER / ORG_ADMIN / PROPERTY_MANAGER / AUDITOR）と
`baseline.override`（OWNER / ORG_ADMIN のみ / §5.5）。
**`CLEANER` / `INSPECTOR` は 404。** ベースラインは P4 の閾値そのもので、
現場に見せると「この枚数までなら」を示すことになる。
