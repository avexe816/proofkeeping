## 測るときに気をつけること（2026-08-22 追記 / DECISIONS #252）

### `CHECKOUT` と `STAYOVER` を分けて数える必要がありうる

**滞在中清掃（`STAYOVER`）のリネン系の差異は、退室清掃より確信度が
構造的に低い**（OPEN_QUESTIONS #119）。

- 滞在中はリネンを交換しない運用があり、回収 0 が正常。そのため
  除外ルール①を当てていない（#252 決定 B）
- **その結果「交換しなかった 0」と「交換したのに記録漏れの 0」が
  どちらも母数に残る。** データ上まったく区別できない
- ベースラインが実態より低く出るぶん、**誤検知が増える側へ倒れる**

**全体で 30% 未満でも、`STAYOVER` だけで見ると超えていることがありうる。**
分けて数えて、差が大きければ #119 の選択肢（交換の有無を記録する列を足す /
確信度を下げる / `STAYOVER` ではリネン系ルールを回さない）を検討する。

### `FACE_TOWEL` を除外ルール①へ足すかを判断する

**いまは足していない**（#252 決定 A の 4）。用意されても客が使わないことが
あり、0 が正常でありうるため。**実データで 0 の出方を見て決める。**

- `bedsUsed > 0` かつ `FACE_TOWEL = 0` が**ほぼ無い**なら、0 は入力漏れと
  みなせるので `ALWAYS_CONSUMED_ITEM_CODES` へ足す
- **一定の割合で出るなら足さない**（足すと見逃す側へ倒れる）
