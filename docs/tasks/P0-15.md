- 完了条件 4 件すべて達成。
- `apps/web/src/locales/{ja,en}.json` を正とし、`MessageKey` は `ja.json` の
  キーから導く。`en` は部分集合でよく、欠けたキーは `ja` へ落ちる。
  **キー名を返さない**（画面に `nav.dashboard` と出るより日本語が出るほうがよい）。
- `resolveLocale()` はユーザー属性 → 組織既定 → `ja` の 3 段だけ。
  `Accept-Language` / `navigator.language` は読まない（ui-writing.md §1）。
- **補間を実装していない。** 契約 §7.1 は 7 言語を挙げており、
  置換だけの補間は語順の違う言語で破綻する。値を混ぜる画面は
  数値・日付を別要素として組むこと。
- 契約 §7.1 の残り 5 言語（zh-CN / vi / id / my / ne）は `LOCALES` に
  載せていない。**翻訳が揃った言語から足す**（§7.3「機械翻訳のまま使用しない」）。
  空のカタログを先に置くと画面に空欄が出る。
- **ESLint は .json を解析しない。** `pk/no-forbidden-words` の `files` から
  json を外し（parse error になる）、代わりに `locales.spec.ts` が同じ語彙表を
  読んで検査する。語彙表は `packages/config/eslint/rules/forbidden-words-list.js`
  へ切り出した（ルールと spec の唯一の出どころ）。CI の grep も json を含む。
