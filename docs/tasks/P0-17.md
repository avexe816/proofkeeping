## 作業ログ

### 2026-08-12
- 完了条件 3 件すべて達成。
- 粒度は 組織 × 文書種別 × 年度。**年度がインスタンス名に入っていることが
  「会計年度の切替でリセット」の実装そのもの。** リセット API は作らない
  （過去年度のカウンタを初期化できる経路になる）。
- **カウンタは同期で進めてから永続化する。** 逆順にすると、同時に届いた
  2 件が同じ値を読んで重複する。永続化に失敗した番号は飛ぶ（欠番）が、
  billing.md §5 は欠番を許容している。
- 番号を戻す API を作らない。取消時も欠番のまま残る。
- 500 並列で欠番・重複ゼロを spec で検証（testing.md §5）。DO の殻ではなく
  `DocumentCounter` を直に回している（workerd 無しで決定的に回すため）。
- 書式（`INV-2026-0042`）と会計年度の判定は `packages/billing` の純粋関数。
  **番号に載る西暦は「会計年度が始まった年」。** 暦年にすると 3 月と 4 月で
  同じ番号が 2 回出る（billing.md §5 の 2 つの MUST を両立させる唯一の読み方）。
- wrangler.toml へ 4 環境ぶんの binding と `[[migrations]] tag = "v1"` を追加。
  **既存タグを書き換えないこと。** クラスを増やす task は新しいタグを追記する。
