## 背景
`ui/navigation.ts` の `nav.inspection` は **`PLANNED`（準備中）のまま**で、
到達先が無い。検査そのもの（API・状態遷移）は P2 で実装済みなので、
**足りないのは一覧画面 1 枚。**

## やること
検査待ちのタスクを施設横断で並べる一覧。**清掃会社の担当者が
「次に検査するもの」を選ぶための画面。**

- 検査待ち（`AWAITING_INSPECTION`）のタスクを業務日で絞って一覧
- 施設・客室・完了時刻を表示（**担当者は出さない** / INV-09・下記）
- 行から検査画面へ遷移する
- `nav.inspection` を `PLANNED` → `READY` にする

## やらないこと
- **検査の実装そのもの**（P2-05 が持つ）
- **自動の優先度付け・スコア表示**（CLAUDE.md §4「個人評価を作らない」）
- 経過時間の赤色表示（ui-writing.md §3「急かさない」）
