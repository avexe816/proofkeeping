## 作業ログ

  - `packages/integrations/src/core/circuitBreaker.ts`（純粋関数）。
    `retryDelaySeconds()` が 5 分 → 15 分 → 60 分、4 回目は `null`。
    `shouldOpenCircuit()` は `consecutiveFailures >= 5`。
  - `openIntegrationCircuit()` / `reactivateIntegration()`（リポジトリ）。
    **`SUSPENDED` は上書きしない**（利用者が明示的に止めた状態）。
  - 汎用 Webhook の取込（P6-04）が `openCircuitIfNeeded()` を呼ぶ。
    **「今回開いたのか、既に開いていたのか」を返す。** 毎回の失敗で
    `integration.error` を送らせないため（通知そのものは P6-09）。
  - Queue の再送に遅延を付けた（`message.retry({ delaySeconds })`）。
    既定の数秒間隔だと `consecutiveFailures` が障害の長さではなく
    再送の速さを映し、5 回の閾値が意味を失う。
  - `POST /api/v1/integrations/:integrationId/reconnect` を置いた。
    **開ける仕組みだけを実装して閉じる仕組みを持たない状態を残さない**
    （DECISIONS #145）。
