### 決定したこと

- **実体のない script を定義しない**（DECISIONS #004）。
  `dev` / `db:generate` / `db:migrate` / `db:seed` / `test:e2e` は担当 task が実体と同時に追加する。
- **`test:isolation` は P0-01 で定義した。** CI の `tenant-isolation` ジョブが呼ぶため。
  `tests/tenant-isolation/` は空で、`--passWithNoTests` により緑になる。実体は P0-13。
- **UI フレームワークを選定しなかった。** OPEN_QUESTIONS #001 と PK-SPEC-P0 §20 が
  「1 週間の技術検証で決める」として明示的に保留しているため、推測で決めない。
  `apps/web` は Hono のインスタンスを生成して `export default` するのみ。
- **`.github/workflows/ci.yml` を 1 行だけ修正した。** `pnpm/action-setup` の `with: { version: 9 }`
  を削除し、root の `packageManager: pnpm@10.33.0` に従わせる。指定が二重になると action がエラーになる。
- **`pnpm-workspace.yaml` に `onlyBuiltDependencies: [esbuild]` を追加した。**
  pnpm 10 は既定でビルドスクリプトを実行せず、Vitest が依存する esbuild のバイナリが配置されないため。
