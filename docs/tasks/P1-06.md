**判断したこと**

1. **実施結果を 3 値にした**（`DONE` / `COULD_NOT` / `NOT_APPLICABLE`）。
   仕様 §2.1 は `isChecked: Boolean` だが、INV-22 が「2 値にしない」と定める。
   → DECISIONS #031 / OPEN_QUESTIONS #032。
2. **一括更新の API を作らない。** 画面から「すべてチェック」を消しても、
   まとめて送れる口があれば同じことができてしまう（§6.3）。
3. テンプレートの読み取りは組織条件だけで絞る（施設列で絞らない）。
   組織共通テンプレートは `propertyId = null` なので、施設スコープで絞ると
   清掃員のチェックリストが空になる。書き込みは権限が守る。
4. 滞在清掃の「シーツを交換した（3泊目のみ）」は**任意項目**にした。
   周期の判定は実装しない（施設ごとの設定可否は §17-2 の未決事項）。
