## 読むべきルール
- .claude/rules/ui-writing.md §3

## やること
- 担当施設が 4 以上の場合、起動時に施設選択画面を表示
- 閾値を組織設定で 2〜10 の範囲で変更可能にする
- 選択後も上部の「🏢 N施設を担当」から他施設へ移動できる
- 翌日以降のタスクは表示のみ（開始不可）
- 選択した施設をセッションに保存し、当日中は再表示しない

## 完了条件
- [x] 4 施設以上で起動時に施設選択画面が出る
      → M-02 の loader が `decidePick()` で判定し `/m/select-property` へ 302。
- [x] 3 施設以下では出ない
      → `needsPropertyPicker()`。**比べるのは当日の担当施設数**（DECISIONS #043）。
- [x] 閾値が組織設定で変更できる
      → `organization.property_selection_threshold`（既定 4・範囲 2〜10）と
      `PATCH /api/v1/organization/settings`。**画面は作っていない**（DECISIONS #046）。
- [x] 翌日以降のタスクが表示のみで開始できない
      → `startable`。仕様どおり**選べるが開始できない**（DECISIONS #042）。
      翌日 1 日ぶんだけを出す（OPEN_QUESTIONS #042）。
- [x] 選択後に他施設へ移動できる
      → M-02 上部の「🏢 N施設を担当」が選択画面へのリンク（§19.4）。
- [x] 当日中は選択画面が再表示されない
      → セッションの `mobilePick.pickedOn` が当日の業務日である間は出さない
      （DECISIONS #044）。**業務日で見る**ので深夜勤務の途中で出直さない。
- [x] 選択ボタンが 64px 以上
      → `.pk-m-pick__item` / `.pk-m-button--tall`（`styles/mobile.css`）。
