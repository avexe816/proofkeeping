**画面（`/plat/usage`）**
- 品質の表は **下位から**。並べ替えの鍵は ①該当した指標の数が多い順 →
  ②完備率の低い順 → ③名前。**完備率が出せないテナントを先頭に置かない**
  （記録が無い日は「悪い」ではない）。並び順が仕様なのでテストで固定した。
- 判定の閾値は PF-14 の運用設定から読む（`judgeTenantQuality()` に渡す）。
- 割合が出せないときは「記録なし」、計測が無いときは「未計測」。**0% にしない。**

**置かなかったもの（出す元が無い / DECISIONS #238 と同じ扱い）**
- KPI「アクティブ端末」— 端末の登録簿が無い
- カード「ストレージと通信」— 測っていない
- 「記録数の推移（直近 6 か月）」— スナップショットは PF-02 が動き出した日
  からしか無く、**6 か月ぶんを出せるのは半年後。** 出せない期間を 0 の棒で
  埋めない
- 月のセレクトと CSV 出力 — 日次の集計が 1 日ぶんしか溜まっていない段階で
  月を選ばせても中身が無い（簡素化は必須）
- **これらを「未計測」と明示するカードを 1 枚置いた**（空欄で察させない）
