## 作業ログ
2026-08-12 実装。`apps/web/src/routes/m/login.tsx`。

- 3 項目は **`orgShortId` + スタッフ番号 + PIN**（security.md §2 / DECISIONS #018）。
  プロトタイプの「施設コード」は組織 ID のこと。**施設ごとのコードで入る認証は
  存在しない。** 見出しも「組織 ID」にした。
- PIN は画面内テンキー（ui-writing.md §3「数値入力にキーボードを出さない」）。
  伏せ字のドット表示のみで、表示切替ボタンは置かない。
- タップ領域はテンキー 60px・主要ボタン 56px・入力欄 56px（`styles/mobile.css`）。
- レート制限は API と同じバケツ（`consumeRateLimit(env, "pinLogin", ip)`）。
  画面経由で 20 req/分/IP を回避できる抜け道を作らない。
- 失敗の文言は 3 種類（拒否 / レート制限 / 形式）。**理由を分けない。**
- **`pinMustChange` を見ていない。** PIN 変更画面の task が P1 に無い（#037）。
- 言語切替は置いていない。翻訳が揃うのは P1-18。
