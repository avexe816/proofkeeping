- 経過は loader が `summarizeTimeLogs()` で実作業時間を出し、作業中なら画面が
  1 秒ごとに足す。**中断中は増えない**（M-02 の時計と意味が違う）。
- 色は `elapsedToneOf()`（engine）。`NORMAL` / `OVER`（オレンジ）/
  `FAR_OVER`（グレー）の 3 値で、**赤に相当する値を返さない**（INV-05）。
  spec が「返る値に DANGER が無い」ことを固定している。
- 「完了する」は必須未記録・写真不足があれば非活性にし、件数を直下に出す
  （§9.3 / §5.3 の 2 つの MUST）。判定は `checkCompletion()`。
- 中断・入室不可は理由を選ばせる。**「その他」を常設し説明を求めない**（INV-24）。
- メモは中断・完了に添えて送る（`note`）。**メモだけを保存する API は無い。**
