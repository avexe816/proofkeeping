### 2026-08-13 追記 — 実機で通しに回らなかった原因の修正

**症状**: M-08 / M-09 に到達できない。清掃タスクの自動生成
（`POST /api/v1/tasks/generate`）が 500 になり、タスクが 1 件も作られない。

**原因**: `expandChecklist()`（P1-06）が **1 塊 60 行**で
`task_checklist_result` を挿入していた。1 行 11 変数なので **660 変数**の文で、
**D1 は 1 ステートメント 100 変数まで**（実測で確認）。
コメントは「SQLite の既定上限（999 変数）に収まる塊へ割る」と書いてあり、
**D1 の上限を SQLite 本体の上限と混同していた。** DECISIONS #075。

**M-09 そのものの不具合**: `listInspectionItems()` が `listTemplateItems()`
（`templateId` で絞る）へ**項目 ID** を渡しており、0 件が返って
**項目名とセクションが常に空欄**だった。P2-07 / P2-08 の PR で
`listChecklistItemsByIds()` を足して修正済み。

**通しの確認**（ローカル / seed 60 室）:

| 段 | 結果 |
|---|---|
| タスク自動生成 | 60 件作成・チェックリスト 1,020 行展開 |
| 清掃完了 | `AWAITING_INSPECTION` / `CLEANING_COMPLETION` の証跡 1 件 |
| M-09 検査実施 | 200。17 項目が**セクションと項目名つき**で表示される |
| 検査不合格（写真必須も検証） | 写真なしは 409 `DEFECT_DETAILS_REQUIRED` |
| 検査確定 | `FAIL` / `REWORK` / `reworkCycle` 生成 / `INSPECTION_FAIL` の証跡 |
| M-12 再清掃 | 200。§11.4 のワイヤーどおり（浴室 > 鏡 / 水滴跡 / 指示 / 写真） |
| 再清掃 開始→完了 | `RESOLVED` / タスクは `AWAITING_INSPECTION` へ戻る |
| 再送 | `unchanged: true`（状態を二重に書かない） |
| 証跡の連鎖 | 3 件すべて `payload` / `chain` / `link` 一致 |
| 改ざん検出 | payload 書き換え → `payloadMatches: false` |
| 行の抜き取り検出 | 途中 1 件削除 → `linkMatches: false` |

**申し送り**: `apps/web/.dev.vars` が無いと `SESSION_SECRET` が空文字になり、
ログインが `INTERNAL_ERROR`（HMAC の鍵長 0）で落ちる。原因が応答から
読めないので、ローカルの立ち上げで必ず詰まる。
**起動時に必須 secret を検査して分かる形で落とすべき**だが、
この修正の範囲外なので手を付けていない。
