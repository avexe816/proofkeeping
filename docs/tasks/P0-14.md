- **UI フレームワークは React Router v8 の framework mode**
  （`react-router` 8.3.x + `@react-router/dev` + `@cloudflare/vite-plugin`）。
  OPEN_QUESTIONS #001 を解決。判断は人間（技術検証は不要との指示）。
  Remix v2（`@remix-run/*`）は 2025 年以降メンテナンスのみで、
  **Remix の直系の後継が React Router の framework mode**。DECISIONS #026。
- **`jsx: "react-jsx"` / `jsxImportSource: "react"`、`include` に `src/**/*.tsx`。**
  P0-04 からの申し送りを消化した。これで `pk/no-literal-string` と
  `pk/no-forbidden-words` が実ファイルに当たる（日本語を直書きした `.tsx` で
  実際に検出されることを確認した）。
- **表示中の施設は `SessionRecord` の省略可能フィールド。** DECISIONS #027。
  版（`v`）は上げていない（省略可能な列の追加は後方互換）。
- **Tailwind / shadcn は導入しない。** DECISIONS #028。v3 標準の寸法とトークンだけ。

### 判断の記録

- **権限が無い項目は「非表示」、未購入は「グレー＋案内」。** 扱いを分けている。
  `CLEANER` / `INSPECTOR` に差異レポートをグレーで見せると
  「契約すれば見られる」と読め、security.md §1 の 404 の境界と食い違う。
- **ナビの `action` は暫定。** P0-10 が「各画面の権限はその画面を作る task が
  `PERMISSION_ACTIONS` に足す」と定めているため、既存 11 アクションのうち
  「到達の前提として最低限必要な操作」を置いた。各画面の task が差し替える。
- **プロトタイプのログイン画面を再現していない。** メール欄・SSO・二要素認証は
  実装のある認証（P0-08 の 3 フィールド）と合わない。見た目だけ先に作らない。
- **通知の鈴を置いていない。** 数える対象が P0 に無く、0 件ならバッジを出さない
  規定（A01 §3.2）に従うと常に空になる。
- **`"ALL"`（全社サマリー）の受け口を開けていない。** 判定（全社ビューを持たない
  ロールは 403）と画面が揃う P0-21 が広げる。
