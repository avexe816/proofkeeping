## 作業ログ

### 2026-08-14
- 語彙表（`packages/config/eslint/rules/forbidden-words-list.js`）に
  **「検知」を足した。** ui-writing.md §2 の表には「不正検知」しか無いが、
  PK-SPEC-P4 §1.1 MUST は単語としての「検知」も出さないと定める。
- ESLint（`pk/no-forbidden-words`）の対象に
  `packages/engine/src/reconciliation/**` と
  `apps/web/src/lib/reconciliation/**` を足した。
  **API レスポンスに載る日本語は照合エンジンが作っていた**
  （`FindingDraft` の `title` / `summary` が `auditFinding` を経て
  `GET /api/v1/findings` と W-07 にそのまま出る）。
  spec は対象外（テスト名は画面に出る文言ではない）。
- CI に単語単位の grep を 1 本足した。**対象は `locales/` だけ。**
  画面に出る文字列しか入っておらず、コメントも識別子も無いので、
  素の grep で誤検出が出ない唯一の場所。
  UI（.tsx）・PDF・engine は ESLint が**文字列リテラルだけ**を見る
  （禁止語を説明した doc コメントに引っ掛からない）。

## 止まらずに判断したこと
- **免責文（§7.2）だけ検査を外した。** ui-writing.md §2 は「不正」を
  禁じるが、§7.2 の全文固定の免責文は「不正行為を認定するものでは
  ありません」と**否定するために**その語を要する。
  `eslint-disable-next-line` を 1 行だけ置き、理由をコメントに残した。
  他の場所でこの逃げ道を使わないこと。
