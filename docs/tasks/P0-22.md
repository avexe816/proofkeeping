## やること
- 範囲一括登録（例 `301-320`、欠番除外に対応）
- CSV 取込
- `Room` に `isSellable` / `sourceType` / `externalRoomId` カラムを追加
- 清掃専用の部屋（パントリー・備品庫等）を `isSellable = false` で登録できるようにする
- 客室ボードで `isSellable = false` を別セクション表示

### 方式B（PMS連携）は P6 で実装する。P0 では以下のみ準備
- 上記 3 カラムの追加
- `externalMapping` テーブルの定義（使用は P6）

## 完了条件
- [ ] 100 室の範囲一括登録が 3 分以内
- [ ] 欠番除外（`304, 314` を除く等）ができる
- [ ] 既存の部屋番号がスキップされ、件数が表示される
- [ ] CSV 取込で `isSellable = false` の部屋を登録できる
- [ ] 清掃専用の部屋が客室数の集計に含まれない
- [ ] 清掃専用の部屋が稼働照合の対象外になる（P4 で検証）
- [ ] 客室を無効化する際、未完了タスクの件数が提示される
- [ ] 部屋番号変更が `AuditLog` に旧番号付きで残る
- [ ] 客室の物理削除 API が存在しない
