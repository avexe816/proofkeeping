## 作業ログ

### 2026-08-14
- `GET /api/v1/rule-configs?propertyId=` と
  `PATCH /api/v1/rule-configs/:ruleCode`、画面 `/app/settings/rules`。
- **経路が §8 と違う**（`:id` ではなく `:ruleCode`）。`ruleConfig` は
  行が無いのが既定の状態で、まだ触っていないルールには `id` が無い
  （DECISIONS #118）。`upsertRuleConfig()` が無ければ作る。
- 一覧は **§3.1 の 14 個すべて**を返す。engine に実体が無い 4 つも
  `isImplemented: false` として出す（隠すと「設定したのに何も起きない」
  理由が読めない / OPEN_QUESTIONS #066）。
- 権限は §6.4 の表どおり `OWNER` / `ORG_ADMIN` だけ。**閲覧も施設責任者に
  開いていない**（閾値は判定の内側の値で、`baseline.read` と同じ扱い）。
  `AUDITOR` は読み取りのみ。
- **消す口が無い。** 既定へ戻すのは既定値を書くこと。行を消すと
  「既定に戻した」と「一度も触っていない」が `rulesetHash`（§2.4）から
  区別できなくなる。
- 「engine を変更せずに調整できる」は元から成り立っている
  （`evaluate()` が `RuleSetting` を受け取る形 / P4-03）。この task が
  足したのは**書き込む経路**。
