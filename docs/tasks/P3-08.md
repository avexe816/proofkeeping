## 作業ログ
2026-08-13。`packages/engine/src/baseline.ts`（41 テスト）。

`computeBaseline(samples, options)` が
`{ baselines, exclusions, consideredCount }` を返す（DECISIONS #095）。
仕様の戻り値は統計量だけだが、§5.3 MUST の除外記録を純粋関数から
渡す経路が要る。**除外条件をバッチ側に書かないこと。**

- 百分位は線形補間。20 件程度で p10 / p90 が階段状に飛ばないようにした。
- 標準偏差は母集団（n で割る）。n = 1 で 0 除算にしないため。
- 統計量は小数第 4 位で丸める（実行ごとに末尾が揺れないように）。
- 集計ウィンドウは `window: { from, to }` で受け取る。
  §5.4 の「直近 90 日」を日付に直すには現在時刻が要るので、
  変換は呼び出し側（P3-09）が行う。
- 並び順はキー昇順。入力順に依存しない。

**除外の順序は仕様の並び順で、1 件 1 理由。** 複数当たっても先勝ちに
するのは、W-22 で理由別の内訳を足したときに合計が件数を超えないため。

**②「中央値の 5 倍超」は中央値が正のときだけ当てる**（DECISIONS #096）。
無条件だと中央値 0 の品目（ミネラルウォーター等）で、実際に使われた日が
全部消えて p90 が 0 に固定される。

**①「値 0 かつ `bedsUsed > 0`」は仕様どおり全品目に当てた。**
アメニティでは「泊まったが使わなかった」を落としてしまう。
