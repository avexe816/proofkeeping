### 完了条件の確認
- **5 回リトライして無効化される** → `outboundDelivery.spec.ts` が刻みと
  閾値を、消費側が「5 回目で `isActive = false` にして通知する」を持つ。
- **署名付きで送信される** → `HMAC-SHA256(secret, "{timestamp}.{生の本文}")`。
  **署名鍵が無ければ送らない**（受け取る側が検証できない配信をしない）。

### 止まらずに判断したこと
- **2xx だけを成功とする。** 3xx を成功に数えないのは、リダイレクト先へ
  署名付きの本文を送らないため。4xx も失敗として数えるが、5 回で
  無効化されるので放置にならない。
- **本文に ID までしか載せない**（ui-writing.md §6）。受け取った側は
  `targetId` で公開 API を引く。そちらはスコープで守られている。
- **こちら側で重複を止めない。** 相手が 200 を返さなかった以上、届いて
  いない可能性の方が高い。`eventId` を渡して受け取る側に排除させる。

  リポジトリ関数は置いてある。
