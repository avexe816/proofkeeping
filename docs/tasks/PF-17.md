# PF-17 運営担当者の 2 要素認証（TOTP＋復旧コード）

**系列**: PF（起票 2026-08-20 / **オーナー判断** DECISIONS #241）
**依存**: PF-01 **見積**: 2日 **ステータス**: 未着手
**仕様**: `docs/PK-IMPL-CONTRACT.md` §3.5（メール＋パスワード＋2FA）

## 背景
PF-01 は方式が決まっていなかったので `two_factor_secret` の列だけを置いた
（OPEN_QUESTIONS #109）。オーナーが **TOTP** を選んだ。

## やること
- **TOTP。** プラットフォーム運営担当者は**必須**（任意にしない）。
- **復旧コードを同時に発行する。**
  - **1 回だけ表示する。** 再表示できる実装にしない
    （公開 API キーと同じ扱い / security.md §7）
  - **DB にはハッシュだけ**を保存する
- **試行回数制限**を入れる（パスワードと同じ考え方 / security.md §2・§8）
- **監査ログ**に残す（登録・使用・復旧コードの消費・再発行）

## やらないこと
- **SMS 2FA**
- **email OTP を正式な第 2 要素にすること**（通知の宛先としてのみ）
- 復旧コードの平文保存・再表示
- **Passkey / WebAuthn**（**後続 task として残す**。ここでは作らない）

## 完了条件
- [x] TOTP を登録していない運営担当者がログイン後の画面へ到達できない
- [x] 復旧コードが**1 回だけ**表示され、DB にはハッシュしか無い（走査テスト）
- [x] 復旧コードは 1 本につき 1 回しか使えない
- [x] 試行回数制限が効く
- [x] 登録・使用・消費・再発行が `platform_audit_log` に残る
- [x] secret・復旧コードがログにも監査ログの `detail` にも出ない

## 作業ログ
- 2026-08-21 実装（実装パラメータの判断は DECISIONS #243）。
  - migration **0034**: `platform_operator` へ 2FA の 4 列
    （`two_factor_confirmed_at` / `two_factor_failed_attempts` /
    `two_factor_locked_until` / `two_factor_last_step`）と
    `platform_recovery_code`（**ハッシュのみ**）を追加。
  - TOTP の機構は `apps/web/src/lib/auth/totp.ts`（RFC 6238 / SHA-1 /
    6 桁 / 30 秒 / 窓 ±1。Appendix B のベクタで固定）。
  - 流れは `lib/platform/twoFactor.ts`: パスワード → `PASSWORD_ONLY` の札
    （10 分）→ `/plat/2fa`（登録済み）または `/plat/2fa/setup`（未登録・必須）
    → 通ったら `COMPLETE` の札（12 時間）。`requirePlatformOperator()` は
    `COMPLETE` 以外を **404**。
  - 復旧コード 10 本（`XXXXX-XXXXX`）。表示は確定応答の 1 回だけ。
    使用は 1 本 1 回（`used_at IS NULL` 条件の UPDATE）。再発行は
    `/plat/2fa/recovery`（現在の TOTP コードが要る）。
  - 試行回数制限: 5 回失敗で 15 分ロック（PIN 準拠）＋ IP は `login` バケツ。
  - 監査: `platform.2fa.enrolled` / `platform.2fa.verified` /
    `platform.2fa.failed` / `platform.2fa.recovery.used` /
    `platform.2fa.recovery.regenerated`。`platform.login` は第 2 要素
    通過時に移動。secret・コード・OTP は `detail` に入れない
    （`twoFactor.spec.ts` が全監査呼び出しの JSON を走査して固定）。
  - **staging へ 0034 は未適用**（このセッションは dispatch 禁止の指示）。
    PF-16 の開通より前に当てること。
- 2026-08-21 レビュー反映（DECISIONS #244）。

    `changes = 1` の 1 本だけが成功し、セッション発行と `platform.login` も
