## 作業ログ
- 2026-08-13 完了。記録・スキップ・リネンの 3 経路を P1-12 のキューへ載せた。
  `enqueueJson()` が積んだ id が `Idempotency-Key` になり、サーバーは

- **断り方を 400 に統一した**（DECISIONS #100）。409 はキューが「処理済」と

  弾くと、オフラインで溜めた記録が復帰後に消える（§8 MUST）。
