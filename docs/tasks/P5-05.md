## 作業ログ

- `packages/billing/src/period.ts` — 純粋関数。
  - `closedPeriodAsOf(closingDay, onDate)` が「直近に締まった期間」を返す。
    締め日は取引先ごと（31 は月末の意味）。20 日締めの 9 月分は 8/21〜9/20。
    **締め日当日はまだ締めない**（その日の作業がまだ増えうる）。
  - `evaluateBillingPeriodTransition(current, action)` が §6.1 の 5 状態を
    扱う。`REJECT` は `REVIEWING` からも `AGREED` からも戻れる。
    発行済み（`INVOICED`）は差し戻さない（訂正は赤伝 / §5）。
  - `counterpartyPropertyScope(rules)` が取引先の施設範囲を料金設定から
    導く（OPEN_QUESTIONS #071）。
- `apps/web/src/lib/billing/monthlyClose.ts` — Cron の入口。
  取引先ごとに期間を起票し `OPEN → REVIEWING` へ進める。**冪等**
  （`uq_period` ＋ 楽観ロック）。3 回走らせても結果が変わらない。
- `apps/web/src/routes/api/v1/billingPeriods.ts` — `GET` と
  `POST /:id/aggregate` と `POST /`。**`agree` / `reject` /
  `request-review` は作っていない**（P5-12 の範囲。§6.2 MUST の
  コメントを伴わない差戻しを記録に残さないため）。
- 監査 `billingPeriod.statusChanged` を追加。
