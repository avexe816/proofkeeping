### 完了条件の確認
- **10 イベントが定義されている** → `NOTIFICATION_EVENTS` が 10 件で、
  `packages/db` の語彙と一致することを spec で検査。
- **`CLEANER` に `task.rework_assigned` 以外が届かない** → 表の `audience` と
  `CLEANER_ALLOWED_EVENT` の**二重**で締めた（DECISIONS #147）。
  9 イベントすべてについて判定と配信の両方で検査している。
- **静音時間が機能する** → 22:00-07:00 で `PUSH` / `LINE` を落とし、
  `EMAIL` は落とさない。**例外は `issue.critical` だけ**（§5.3）。
  日をまたぐ窓・境界（22:00 は含む / 07:00 は含まない）も spec に入れた。
