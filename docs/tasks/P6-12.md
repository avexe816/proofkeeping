### 完了条件の確認
- **キーが作成時のみ全体表示される** → 保存する 2 つの値（`keyPrefix` /
  `keyHash`）に平文も秘密の断片も現れないことを spec で検査。
  再発行・再取得の口が無いことをソース走査で固定。
- **7 スコープが機能する** → 足りなければ 403（401 と区別する）。
  ワイルドカードを実装していないことも検査。
- **`propertyIds` 制限が機能する** → `null` / 配列 / `[]` の 3 通りを区別。
  範囲外は **404**（403 は施設の存在を示唆する）。
- **レート制限が機能する** → 600 / 60 / 300 req/分/キー。
  識別子は**トークンのハッシュ**（平文を KV のキー名にしない）。

### 止まらずに判断したこと
- **#151 公開 API で `assertPermission()` を呼ばない。** `TenantContext.role` は
  リポジトリ層の施設スコープを効かせるためだけの値。**`public.spec.ts` が
  ソースを走査して固定している。**
- **#152 公開 API は ProofKeeping の ID だけを受け取る。** 外部 ID の変換は
  汎用 Webhook（§4.2）の担当で、経路を 2 つ持たない。
- **#153 公開 API からの稼働記録は `PMS_API` を名乗る。** P4-02 の
  「API 越しに名乗らない」は人の口の話。`importedById` は API キーの ID。
