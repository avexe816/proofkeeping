## 背景
プロトタイプ 07 のカード「📅 在留資格の管理」は、内訳（特定技能1号 18 名 …）と
トグル 3 つを持つ。**通知は 90 日前と 30 日前の 2 段**で、仕様 §1.4 の 60 日は無い
（DECISIONS #221）。

## やること

### `residencyRecord` テーブル
仕様 §1.4 の定義どおり。`statusType` / `statusLabel` / `expiresOn` /
`renewalAppliedOn` / `workPermitRequired` / `weeklyHourLimit` / `note` /
`updatedById`。

### 権限（**INV-08 を採る** / OPEN_QUESTIONS #110）
| ロール | `residency.read` |
|---|---|
| `ORG_ADMIN` | 組織全体 |
| `PROPERTY_MANAGER` | **件数のみ**（一覧に到達させない） |
| `OWNER` | `DENY`（INV-08 が名指しで除外） |
| `VENDOR_ADMIN` / `INSPECTOR` / `CLEANER` / `AUDITOR` | `DENY` |
本人が自分の記録を見る経路は別に置く（security.md §5 の M-11 と同じ扱い）。

### アラート（Cron 07:00 JST）
```
expiresOn - today = 90日 → 画面 + メール
                    30日 → 画面 + メール（毎日再通知）
                     0日 → 期限切れ。新規タスク配分を停止
```
- 停止の解除は `ORG_ADMIN` が `expiresOn` を更新したときだけ。
  **手動の解除ボタンを作らない**（仕様 §1.4 MUST）。
- 既存の未完了タスクは残す（現場を止めない）。

### 画面への固定表示（**編集不可**）
> 在留資格に関する判断は、出入国在留管理庁の定めおよび最新の運用に従い、事業者様の責任で行ってください。本機能は期限の管理を支援するものであり、就労可否を判定するものではありません。

プロトタイプの警告 2 本もそのまま置く（**逐語**）:
> **期限切れの状態で就業させることは法令違反です**
> 更新手続きの確認は雇用主の義務です。システムは通知と割当停止までを行いますが、手続きの管理は人が行ってください。

## やらないこと
- **在留資格の種類から就労可否を自動判定しない**（仕様 §1.4 MUST）
- 60 日前の通知（プロトタイプに無い）
- パスポート番号・在留カード番号の保存（security.md §3）

## 完了条件
- [ ] 90 日前・30 日前で段階的に通知が出る（境界値のテスト）
- [ ] 期限切れで**新規**タスク配分が止まり、既存の未完了タスクは残る
- [x] `OWNER` が `residency.read` に届かない、`PROPERTY_MANAGER` は件数だけ
      （`PERMISSION_MATRIX` と `countExpiringResidencies()`）
- [x] 免責文が画面に固定で出る（`staffScreen.spec.ts` が文言まで見る）
- [ ] 編集が `recordAudit()` を呼ぶ（**編集の画面がまだ無い**）
- [x] テナント越境テスト 4 パターン（`tests/tenant-isolation/residency.spec.ts`）

## 作業ログ

- 2026-08-20 **土台まで。** `residency_record` と 4 つのリポジトリ関数、
  `residency.read` / `residency.write`（INV-08 に合わせて `ORG_ADMIN` だけ）、
  越境テスト、スタッフ一覧の在留期限の列と免責文を入れた。
- **まだ書き込む経路が無い。** 残りは 3 つ。
  1. 在留資格の編集フォーム（`recordAudit()` つき）
  2. 90 日前・30 日前の通知（Cron 07:00 JST）
  3. 期限切れのスタッフを新規配分から外す（`listExpiredResidencyStaffIds()`
     は用意済み。P1-14 の配分から呼ぶ）
- 読める相手には**引かない**形にしてある。`can()` が偽なら
  `listResidencyRecords()` を呼ばず空配列を渡す。引いてから画面で隠すと、
  loader の戻り値（= HTML に載る JSON）に期限が残る。
