### 2026-08-12
- 8 ジョブすべてを独立ジョブとして構成した。1 本にまとめると最初の失敗で
  止まり、どこが壊れているかが 1 回で分からない。
- `migrate` は `drizzle-kit check`（スキーマと `migrations/` の整合）。
  **実 D1 へは接続しない。** 16 シャードへの実適用は P0-02 の完了後。
- `e2e` は `scripts/e2e.ts`。接続先（preview）が無い間は未実施として 0 で抜け、
  `E2E_BASE_URL` が与えられたら「シナリオが無い」と 1 で落ちる。
  **preview が用意できたのに素通しするのを防ぐため。**
  Playwright は入れていない（接続先の無いブラウザテストは書いた本人にも通らない）。
- `preview` デプロイは secrets が無ければ何もせず抜ける（fork の PR を常に
  赤くしない）。必須 8 ジョブには含めない（testing.md §1 の一覧に無い）。
- **未達 2 件:**
  - `main` への直接 push の禁止は **branch protection（リポジトリ設定）**で、
    ワークフローでは表せない。人間が GitHub 側で有効にすること
    （Require a pull request before merging ＋ 上記 8 ジョブを必須チェックに）。
  - PR ごとの preview 環境は P0-02 が実リソースを作るまで動かない。
