**`AdapterConfig` で `settings` と `credentials` を分けた。** 混ぜると
`integration.config`（D1）に秘密が紛れ込む経路ができる。復号は呼び出し側
（P6-02）の責務で、アダプタは受け取って使うだけ。

**語彙は `packages/db` からの写し。** integrations → db の辺を張らないため
（`packages/billing` と同じ扱い）。片側だけ増えたら
`packages/db/src/schema/vocabulary.spec.ts` が落ちる。ずれると
「受信の時点では通り、保存の時点で失敗する」形で壊れる。

**登録簿（vendorCode → アダプタ）は作っていない。** 実アダプタが 1 つも
無い段階では中身の無い分岐になる。P6-06 が最初の 1 社を入れるときに置く。
