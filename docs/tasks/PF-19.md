# PF-19 運営面の 2 段階認証を切り替え可能にする

**系列**: PF（起票 2026-08-21 / オーナー指示） **依存**: **PF-17**
**見積**: 0.5 日 **ステータス**: 実装済（staging は無効で運用中）

## 背景
staging で TOTP の登録が繰り返し通らず、開通した運営担当者が `/plat/*` へ
入れないままになった。**実装を消さずに要求を止める**（DECISIONS #250）。

## 追加したもの
| もの | 中身 |
|---|---|
| `PLATFORM_2FA_REQUIRED`（vars） | 既定 `"true"`。**staging だけ `"false"`** |
| `lib/platform/twoFactorPolicy.ts` | 判定はここ 1 か所。production は値を読まない |

## 読む場所（5 か所）
`login.ts` / `bootstrap.ts`（札の種類）、`requireOperator.ts`（登録済みの検査）、
`routes/plat/login.tsx` / `routes/plat/bootstrap.tsx`（遷移先）。

## 消していないもの
`twoFactor.ts` / `totpSecretBox.ts` / `lib/auth/totp.ts` /
`platform_recovery_code` / `platform_operator` の 2FA 4 列 / migration 0034 /
`/plat/2fa` と `/plat/2fa/setup` の画面。**新しい migration も無い。**

## 穴を作らないための線引き
- **門（`COMPLETE` の札を要求すること）は畳まない。** 外すのは
  `twoFactorConfirmedAt === null` の 1 行だけ
- 切替前に出た `PASSWORD_ONLY` の札は `false` でも 404
- セッションの寿命は 12 時間のまま（`state` が決める）
- **production は `false` にできない**（コードで固定）

## 完了条件
- [x] `false` で TOTP 未登録でも `/plat/*` へ入れる
- [x] `false` でも登録済みに TOTP を要求しない（要件 5）
- [x] `true` のときの挙動が変わらない（既存の検査がそのまま通る）
- [x] `false` でも落ち続ける 7 通りの検査
- [x] 監査に「要求しなかった」ことが残り、秘密が入らない
- [x] runbook に再有効化の手順と登録失敗時の確認順序
- [ ] **staging で運営画面へ入れることの確認**（人が実施）
