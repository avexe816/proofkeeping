## 作業ログ
2026-08-12 実装。`apps/web/src/lib/photo/*` /
`packages/db/src/repositories/taskPhoto.ts` / `POST /api/v1/tasks/:taskId/photos`。

- 撮影は `input[type=file][accept=image/*][capture=environment]`。
  **`getUserMedia()` はリポジトリのどこにも無い。**
- クライアントは canvas（`OffscreenCanvas`）で再エンコードする。長辺 1600px・
  JPEG q=0.7。**再エンコードそのものが EXIF 除去**で、GPS だけを選んで消す
  実装より消し漏れが起きない。HEIC → JPEG も同じ経路で済む。
- サーバー側は `sanitizeImage()` がセグメント単位で APP1（EXIF/XMP）・COM・
  PNG の eXIf/tEXt を落とす。**落とせない形式は 415 で受け付けない。**
  Workers に画像デコーダが無いので HEIC は受けない（クライアントが変換済み）。
- 冪等は `taskPhoto.clientId` の一意制約。再送は R2 へ書かずに既存を返す。
- 上限 20 枚は 409、500KB 超は 413。**`Content-Type` を信用せず中身で判定する。**
- 閲覧は 15 分の署名付き URL。`/api/v1/files/:key` が `photos/` を扱えるよう広げ、
  **キーの組織 ID がセッションと一致しない場合は 404**（署名とは別の照合）。
- `capturedAt` はサーバー時刻（実装契約書 §2.5 優先 / #036）。
