**自動配分は必ずプレビューを挟む**（§4.1 MUST）。action の intent が
`preview` と `apply-auto` に分かれており、`preview` は DB を書かない。

**作業中の担当変更**（§4.2）は `applyAssignments()` が見送り、対象の
taskId を返す。画面が警告を出し、確認して `confirmActive=1` で送り直す。
状態は動かさず担当だけを替える（`IN_PROGRESS` のまま）。

ドラッグ＆ドロップは素の HTML5 DnD。**触れない環境のために一括選択も
残してある。** 片方だけにしないこと。

DECISIONS #036）。空欄にせず「非表示」バッジを出す。

§4.1 の「担当フロアの希望順」は**データが無い**ためスタッフ番号順に
した（OPEN_QUESTIONS #039）。
