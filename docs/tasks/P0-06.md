**完了条件「16 シャードすべてに適用できる」が未チェックの理由**

P0-02 が未完で、実在する D1 は `proofkeeping-shard-00` のみ。
ローカル（`SHARD_COUNT=1`）で以下を実測した。

```
pnpm db:generate --name p0_initial     → 0000_p0_initial.sql（15 テーブル）
pnpm db:migrate --env local --check    → shard 0: 1 pending / exit 1
pnpm db:migrate --env local            → shard 0: applied 0000_p0_initial
pnpm db:migrate --env local （3 回）    → shard 0: up to date（冪等）
sqlite_master                          → 15 テーブル + schema_version
schema_version                         → 0000_p0_initial / checksum / applied_at
```

16 シャードへの順次適用・失敗時の中止・シャード間の不一致検出は
`packages/db/src/migrate.spec.ts` が注入した代役で検証している。
**実 D1 16 本での確認は P0-02 の完了後に行うこと。**
