# プロトタイプと実装の差分台帳

**方針**: 見た目と挙動の正は `ui-prototypes/`（DECISIONS #195 / 人間の指示 2026-08-16）。
P8 に当たるもの・CLAUDE.md §4 と security.md に反するものは作らない。
**2 つの原則を両立させる**（人間の指示 2026-08-16）:
1. **プロトタイプが上限。** 無い機能・画面・項目を足さない。
2. **簡素化は必須。** プロトタイプの範囲内でも、目的に効かない
   装飾・フィルタ・列は削ってよい。迷ったら少ない方を選ぶ。
画面ごとの判断は本台帳の行に書く。

**版**: 2026-08-16（初版）。閉じたら行を更新すること。消さない。

## 凡例

| 状態 | 意味 |
|---|---|
| ✅ | 実装済み（プロトタイプと同等） |
| 🔧 | 実装はあるが、プロトタイプとの差分が残る |
| ⬜ | 未実装（作る側に倒す / DECISIONS #195） |
| 🚫 | 作らない（P8 / 人間の指示 / §4 禁止） |
