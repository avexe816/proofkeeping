# プロトタイプと実装の差分台帳

**方針**: 見た目と挙動の正は `ui-prototypes/`（DECISIONS #195 / 人間の指示 2026-08-16）。
CLAUDE.md §4 と security.md に反するものは作らない。
**2026-08-20 のオーナー指示で、P8 とプラットフォーム運営 12 画面が実装対象に入った**
（DECISIONS #219）。それ以前の「P8 に当たるものは作らない」は解除済み。
**2 つの原則を両立させる**（人間の指示 2026-08-16）:
1. **プロトタイプが上限。** 無い機能・画面・項目を足さない。
2. **簡素化は必須。** プロトタイプの範囲内でも、目的に効かない
   装飾・フィルタ・列は削ってよい。迷ったら少ない方を選ぶ。
画面ごとの判断は本台帳の行に書く。

**版**: 2026-08-20（第2版 / P8・プラットフォームの解禁を反映）。閉じたら行を更新すること。消さない。

| 🚫 | 作らない（プロトタイプに実物が無い / 人間の指示 / §4 禁止） |
