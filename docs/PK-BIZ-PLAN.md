# ProofKeeping 版数構成と価格設計 分析報告

**文書番号** PK-BIZ-PLAN
**版数** 第1版（2026-08-11）
**目的** 製品の版数構成（プラン分け）の是非を判断し、機能差異化・価格・対象顧客を確定する
**関連文書** PK-SPEC-UI、PK-IMPL-CONTRACT、PK-SPEC-UI-A01

---

## 1. 結論

**3段階の機能別プランを採用しません。実質2段階＋契約形態1つとします。**

| 名称 | 性質 |
|---|---|
| Base | 記録の保存と作業管理 |
| Pro | Base ＋ PMS連携 ＋ P4稼動照合 ＋ オーナー共有 |
| Ent | Pro と機能同一。SSO・SLA・API・専任サポートを含む契約形態 |

機能差異は**PMS連携の有無１点のみ**です。これは技術的な依存関係に基づく自然な境界であり、人為的な機能制限ではありません。

## 3. 3段階の機能別プランを採用しない理由

### 3.1 実装契約が主要な差異化材料を禁じている

PK-IMPL-CONTRACT には以下の不変条件があります。

| ID | 内容 |
|---|---|
| INV-35 | 多言語対応をプランで制限しない |
| INV-36 | 記録の保存期間をプランで制限しない |

海外ベンダーが一般的に用いる「多言語は上位プラン」「長期保存は上位プラン」という差異化を、設計方針として封じています。

理由は明確です。Starterプランの施設で働く清掃員も日本語を読ません。利用者1,284名のうち日本語利用者は6.9%であり、**多言語対応は課金で差別化する機能でなく、動作の前提条件**です。保存期間も同様で、証跡としての価値を課金で削ることはできません。

この2つを封じた時点で、機能別3段階の材料はほとんど残りません。

### 3.2 P4を最上位に置くと差異化が伝わらない

同業他社はすべて「タスク管理・状態共有」ツールです。稼動記録と観察記録を突き合わせて差異を検出するP4稼動照合エンジンは、調査した12製品のいずれにも存在しません。

P4を最上位プラン限定にすると、顧客の多数（下位プラン）は**より高価なStayseeを使っているだけ**の状態になります。差異化の核心が体験されないまま解約判断がなされます。

### 3.3 維持コストが規模に見合わない

3プラン × 7言語 × 4アプリケーション（清掃員モバイル・オーナー・清掃会社・運営）＝ 84通りの組み合わせを検証し続ける必要があります。現在の開発規模では、プラン別の分岐がそのままバグの発生源になります。

### 3.4 本当の分岐は機能量でなく「発注元の有無」

| 顧客型 | オーナー画面 | 実態 |
|---|---|---|
| 施設直営（自社雇用の清掃員） | 不要 | 発注元と受注者が同一 |
| 清掃会社（受託運営） | 必要 | 施設オーナーへの報告義務がある |

オーナー画面12画面の価値は、**発注元と受注者が別法人である場合にのみ**発生します。これは機能の等級差でなく構造の違いです。等級で分けるのではなく、構造で分けるべき差異です。

## 4. 版数の設計

### 4.1 差異化の軸

機能の強弱でなく、**PMS連携の有無**を軸にします。

```
PMS連携なし → 稼動予定データがない → P4が動作しない → 差異が出ない
                                                    → オーナーへ共有する内容がない
PMS連携あり → 稼動予定データがある → P4が動作する   → 差異が出る
                                                    → オーナー画面に意味が生まれる
```

これは技術的な依存関係であり、人為的な機能制限ではありません。顧客に説明したときに納得が得られる境界です。

### 4.2 機能配分表

| 機能 | Base | Pro | Ent |
|---|---|---|---|
| **清掃員モバイル 16画面** | ○ 全機能 | ○ 全機能 | ○ 全機能 |
| 7言語対応 | ○ | ○ | ○ |
| オフライン動作 | ○ | ○ | ○ |
| 入室時の記録 | ○ | ○ | ○ |
| チェックリスト・写真・リネン | ○ | ○ | ○ |
| 個人実績のPDF出力（本人向け） | ○ | ○ | ○ |
| **清掃会社PC 12画面** | ○ | ○ | ○ |
| シフトと割当 | ○ | ○ | ○ |
| 検査キュー | ○ | ○ | ○ |
| スタッフ管理・在留期限管理 | ○ | ○ | ○ |
| 研修と資格（7言語教材） | ○ | ○ | ○ |
| **PMS連携** | ✕ | ○ | ○ |
| **P4 稼動照合エンジン** | ✕ | ○ | ○（閾値の個別調整可） |

| **オーナーPC 12画面** | ✕ | ○ | ○ |
| 月次レポート | 施設内向け簡易版 | PDF正式版 | ○＋独自項目 |
| **記録の保存期間** | 同一 | 同一 | 同一 |
| **施設数** | 〜8施設 | 無制限 | 無制限 |
| SAML SSO | ✕ | ✕ | ○ |

| SLA（稼動率保証） | ✕ | ✕ | ○ 99.9% |

| 監査対応（証跡の第三者提出支援） | ✕ | ✕ | ○ |

Entが追加するのは**清掃員もオーナーも目にしない項目のみ**です。SSO・SLA・API・サポート形態は契約条件であり、機能ではありません。

### 4.3 Baseで清掃員アプリを全機能提供する理由

Baseでも清掃員モバイル16画面をすべて提供します。制限しません。

| 理由 | 内容 |
|---|---|
| 記録の質が全プランの前提 | Baseの記録品質が落ちるとPro移行後もP4が機能しない |
| 現場は課金者ではない | 清掃員は契約の当事者ではなく、その体験を課金で削る根拠がない |
| 移行の摩擦をなくす | Base→Proで現場の操作が変わらないため、移行時の再研修が不要 |
| 在留期限管理は法令対応 | 雇用主の義務であり、プランで制限すべきものではない |

### 5.1 価格表

| | Base | Pro | Ent |
|---|---|---|---|
| 室単価 | **240円/室/月** | **420円/室/月** | 480円〜/室/月（見積） |
| 最低利用料 | 20,000円/月 | 40,000円/月 | 個別 |

| 契約期間 | 月次 | 年次（月次は+15%） | 年次 |
| 試用 | 30日無料 | 30日無料 | 個別 |

### 5.2 価格設定の根拠

| プラン | 比較対象 | 設定の考え方 |
|---|---|---|
| Base 240円 | 轟スタンダード 220円 | 7言語対応と在留期限管理を含むため僅かに上。同業に同等機能がない |
| Pro 420円 | 轟上位 440円 | 上位帯の下に置く。P4という同業に存在しない機能を含みつつ価格は超えない |
| Ent 480円〜 | Flexkeeping（見積・$300/月〜） | 海外専業と同水準。SSO・SLA・APIを含む |

**PMSの価格帯（$100〜500/月）には踏み込みません。** 清掃管理として比較検討されるべき製品であり、PMSの代替として比較されると機能量で不利になります。

### 5.3 3年総コストの試算

比較検討時は3年総コストで示すのが業界の慣例です。

**例1：施設直営ホテル 60室（Base）**

| 項目 | 金額 |
|---|---|
| 初期費用 | 0円 |
| 月額（60室 × 240円 = 14,400円 → 最低利用料適用） | 20,000円 |
| 3年合計 | **720,000円** |

**例2：清掃会社 8施設 412室（Pro）**

| 項目 | 金額 |
|---|---|
| 初期費用 | 50,000円 |
| 月額（412室 × 420円） | 173,040円 |
| 3年合計 | **6,279,440円** |

**例3：清掃会社 24施設 1,840室（Ent）**

| 項目 | 金額 |
|---|---|
| 初期費用（個別） | 300,000円 |
| 月額（1,840室 × 480円） | 883,200円 |
| 3年合計 | **32,095,200円** |

### 5.4 課金単位に関する制約

PK-IMPL-CONTRACT の不変条件を再掲します。

| ID | 内容 |
|---|---|
| INV-34 | 課金単位は客室数とする。記録件数・写真枚数・ストレージ容量で課金しない |

同業に「完了1件50円」という従量課金の例がありますが、採用しません。記録件数で課金すると、テナントが**記録を減らすことでコストを下げられる**構造になります。写真を撮らない、入室時の記録をスキップするという行動が経済的に合理化され、P4の精度低下に直結します。

客室数という**記録量と無関係な単位**で課金することが、記録の質を守る前提条件です。

### 6.1 プラン別の対象

| プラン | 対象顧客 | 典型規模 | 月額の目安 |
|---|---|---|---|
| **Base** | 施設直営ホテル・旅館／民泊管理会社／清掃会社の試験導入 | 1〜8施設・〜200室 | 20,000〜48,000円 |

| **Ent** | ホテルチェーン／大手清掃会社／複数社間の連携が必要な事業者 | 30施設〜・1,500室〜 | 720,000円〜 |

### 6.2 顧客の状況別の推奨

| 顧客の状況 | 推奨 | 理由 |
|---|---|---|
| 自社雇用の清掃員で自施設のみ清掃 | Base | オーナー画面が不要。発注元が存在しない |
| 外国人スタッフが多く記録が定着しない | Base | 7言語対応と在留期限管理が全プラン共通で使える |
| PMSを導入していない | Base | P4が動作しないためProの価値が出ない |
| 施設オーナーへの月次報告が必要 | Pro | オーナー画面と正式レポートが必要 |
| 空室のはずの客室で使用痕跡の報告がある | Pro | P4稼動照合が本来の用途 |
| 複数の清掃会社と取引している施設側 | Pro | 施設側がProを契約し、清掃会社に利用させる形も可 |
| 情報システム部門がSSOを要求 | Ent | SAML対応が契約条件になる |
| 監督機関への説明資料が必要 | Ent | 証跡の第三者提出支援を含む |

### 6.3 Base→Proの移行判断

以下のいずれかに該当したらProを提案します。

- PMSを導入した／導入予定がある
- 施設オーナーから清掃実施の証跡提出を求められた
- 稼動記録と実態の乖離が疑われる事案が発生した
- 施設数が8を超えた

移行時に**現場の操作は一切変わりません**。清掃員モバイルは全プラン同一のためです。

### 6.4 規模別の月額対比

| 規模 | Base | Pro | 差 |
|---|---|---|---|
| 60室 | 20,000円 | 25,200円 | +5,200円 |
| 200室 | 48,000円 | 84,000円 | +36,000円 |
| 412室 | —（8施設超） | 173,040円 | — |

60室規模ではBaseの最低利用料（20,000円）が効くため、Proとの差は月**5,200円**です。小規模ほど移行のハードルが低くなります。

## 7. 既存モックの修正点

プラットフォーム運営10画面（契約と収益）で使用した以下を修正します。

| 修正前 | 修正後 |
|---|---|
| Starter / Standard / Enterprise | **Base / Pro / Ent** |
| Starter 500円 / Standard 420円 / Enterprise 480円 | **Base 240円 / Pro 420円 / Ent 480円** |
| 最低利用料により小規模ほど室単価が高い構造 | 室単価は単調増加。最低利用料は別項目として明示 |

修正の理由は、室単価が逆転していると「小規模だから高い」という説明が必要になり、顧客が不利益を感じやすいためです。

## 8. 販売時の説明

### 8.1 同業との違いの説明順序

```
1. 記録が7言語で残る（同業にほぼない）
2. 記録が形骸化していないかを施設側が確認できる（同業にない）
3. 稼動記録との差異を示唆する（同業に存在しない）
4. 清掃員個人の評価には使わない（差別化でなく前提の説明）
```

4番目を必ず伝えます。清掃会社にとっては「発注元が従業員個人を特定できない」ことが契約上の安心材料になり、清掃員にとっては記録に協力する理由になります。

### 8.2 使わない説明

| 使わない | 理由 |
|---|---|
| 不正を検出します | P4は判定する仕組みではない |
| 清掃員の生産性を可視化します | 記録を評価に使わない方針に反する |
| 作業時間を短縮します | 短縮は目的でない。記録が目的 |
| 差異率を0%にできます | 0%にはならない |

### 8.3 試用期間中の確認項目

30日試用の期間中、以下を確認します。定着しない場合は原因を運用側に求めます。

| 確認項目 | 基準 |
|---|---|
| 入力所要時間の中央値 | 20秒以内 |
| 記録の完備率 | 90%以上 |
| 既定値のまま確定した比率 | 70%未満 |
| 1人あたりの担当室数 | 16室以内 |
| 導入研修を母語で実施したか | 全言語で実施 |

過去の解約事例2件はいずれも機能不足や価格でなく、**担当室数の超過**と**研修が日本語のみ**が原因でした。試用期間中にこの5項目を確認する運用にします。
