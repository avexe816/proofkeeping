# ProofKeeping 実行ガイド

## 0. アップロード後、最初にやること

**`docs/PK-SPEC-P0.md` 〜 `P7.md` は現在プレースホルダです。**
会話で生成した 8 冊の仕様書本文を各ファイルに貼り付けてください。

特に P0 は **v1.1（Cloudflare 構成）** を使うこと。
v1.0（Prisma / Neon / Vercel / RLS）を置くと、Claude Code が古い構成で実装してしまいます。

---

## 1. 1 セッションの流れ

### Step 1 — 開始
```
docs/tasks/P0-01.md を読んで、この task を実装してください。
まず plan mode で、変更するファイル一覧・追加する API・追加するテストを提示してください。
```

### Step 2 — 計画の確認
- [ ] task の範囲を超えていないか
- [ ] 禁止事項に触れていないか
- [ ] テストが含まれているか
- [ ] 差分が 800 行を超えそうでないか

超えそうなら task を分割する。

### Step 3 — 実装
途中で以下が起きたら止める。
- task に書かれていない判断が必要 → `OPEN_QUESTIONS.md` へ
- 仕様書どうしが矛盾 → `OPEN_QUESTIONS.md` へ
- 差分が 800 行超 → task を分割

### Step 4 — 検証
```bash
pnpm check
```

### Step 5 — 終了
```
docs/PROGRESS.md を更新して、このセッションを終了してください。
```
その後 `/clear` する。

## 2. コンテキスト管理

### 60% ルール
超えたら作業途中でも一度切る。

### 何を読ませるか

| 状況 | 読ませるもの |
|---|---|
| 常時 | `CLAUDE.md`（自動読込） |
| DB を触る | `.claude/rules/architecture.md` |
| 認証・写真 | `.claude/rules/security.md` |
| 画面を作る | `.claude/rules/ui-writing.md` |
| すべての PR | `.claude/rules/testing.md` |
| 請求を触る | `.claude/rules/billing.md` |
| task 実行時 | 該当 task + 仕様書の**該当章のみ** |

**仕様書を全文読ませない。**「PK-SPEC-P4 の §3.2 だけ読んで」と指定する。

## 3. よくある失敗

### 失敗 1: 仕様書を全部読ませる
```
✕ docs/ 配下を全部読んで、P4 を実装して
○ docs/tasks/P4-04.md と docs/PK-SPEC-P4.md の §3.2 と §3.7 だけ読んで
```

### 失敗 2: 複数 task をまとめる
```
✕ P1-08 から P1-11 までまとめて実装して
○ P1-08 を実装して（完了後に /clear して次へ）
```

### 失敗 3: 禁止事項を忘れる
長いセッションでは定期的に確認させる。
```
実装前に CLAUDE.md §4 の禁止事項を確認してください。
```

### 失敗 4: テストを後回し
```
○ 完了条件のチェックリストをテストとして先に書いて、それが通るように実装して
```

### 失敗 5: 人間の検証を飛ばす
以下は Claude Code では完了できない。
- P1-19 実機テスト
- P1-20 現場検証（2 週間）★出荷判定
- P2-17 現場検証（2 週間）★出荷判定
- P3-13 データ蓄積（4 週間）★P4 の前提
- P4-08 誤検知率の検証（2 週間）
- P7-14 復旧訓練
- P7-17 GA 判定（1 か月）

## 6. 判断に迷ったときの原則

| 迷い | 判断 |
|---|---|
| 機能を足すか、削るか | **削る** |
| 早く出すか、正確にするか | P0〜P3 は正確に。P5 以降は早く |
| 汎用化するか、決め打つか | 決め打つ。実顧客 3 社まで汎用化しない |
| 自動化するか、手動を残すか | 手動の逃げ道を必ず残す |
| 通知するか、画面に出すか | **画面に出す** |
| 検出するか、しないか | 迷ったら検出しない |
| 個人を特定するか、しないか | **しない** |

## 7. リモート開発（macOS 12 以下の場合）

Wrangler は macOS 13.5+、Claude Code は macOS 13.0+ が必要。
古い Mac では以下を使う。

| 方法 | 用途 |
|---|---|
| Claude Code on the web（claude.ai/code） | 主力開発。Max 契約に含まれる |
| GitHub Actions（@claude メンション） | 独立した task の並行実行 |
| GitHub Codespaces（月 120 core-hours 無料） | wrangler dev、UI 調整、E2E |

ローカル Mac は「ブラウザを開く」「Safari で実機検証」だけ担当する。
