## 0. 本追補の位置づけ

PK-SPEC-UI 第2章「デザイントークン」に、レイアウト構造の規定を追加します。**本追補は既存の画面設計より優先します。**

---

## 1. 全体構造

```
┌──────────────────────────────────────────────────────────────┐
│ TOPBAR                       h = 58px   bg = --brandTop      │
│ ┌── brand ──┐ ┌ 施設セレクタ ┐              ┌ 🔔 ┐┌ user ┐ │
│ │  214px    │ │  展開時 404px │     …       └────┘└──────┘ │
│ └───────────┘ └───────────────┘                             │
├────────────┬─────────────────────────────────────────────────┤
│  SIDEBAR   │  PAGE HEADER   画面名 + 期間選択 + 操作ボタン   │
│  214px     ├─────────────────────────────────────────────────┤
│  bg=--brand│  CONTENT                                        │
│  nav のみ  │                                                 │
└────────────┴─────────────────────────────────────────────────┘
```

### 1.1 寸法

| 要素 | 値 |
|---|---|
| topbar 高さ | 58px |
| topbar 背景 | `--brandTop`（サイドバーより濃い緑） |
| ブランド領域の幅 | サイドバー幅と常に同じ値 |
| サイドバーの幅（展開時） | 214px |
| サイドバーの幅（レール時） | 56px（§4.4） |
| 施設セレクタ ドロップダウン幅 | 404px（プラットフォーム運営は430px） |
| ユーザードロップダウン幅 | 258px |
| ページヘッダー パディング | 13px 22px |
| コンテンツ パディング | 20px 22px 30px |

ブランド領域とサイドバーの幅を**常に同じ値に揃えます**（展開時 214px / レール時 56px）。施設セレクタの左端がサイドバーの右端と一致し、縦のラインがどちらの状態でも通ります。

### 1.2 背景色の階層

| 領域 | トークン | 意図 |
|---|---|---|
| topbar | `--brandTop` | 最上位のスコープ |
| サイドバー | `--brand` | ナビゲーション |
| コンテンツ | `--bg` | 作業領域 |

## 2. 施設セレクタ

### 2.1 配置

topbar 左、**ブランドの右隣に固定**します。サイドバー内には置きません。

### 2.2 サイドバーに置かない理由

| 論点 | 判断 |
|---|---|
| 施設はナビゲーション項目か | いいえ。全画面に効くスコープ |
| 影響範囲 | サイドバーの全項目＋コンテンツ |
| 正しい階層 | サイドバーより上位 |

施設を切り替えると、コンテンツだけでなく**サイドバーの内容（バッジの件数など）も変わります**。自分自身を切り替える要素がナビゲーションの一部に見えると階層が逆転します。

### 2.3 ドロップダウンの構成

各施設の状態を**3つの数字で要約表示**します。切り替える前に「どの施設が要対応か」が分かる状態にします。

| 数字 | 意味 | 色 |
|---|---|---|
| 1つ目 | 完了 | `--ok` |
| 2つ目 | 作業中 | `--warn` |
| 3つ目 | 要対応（差異＋再清掃） | `--danger` |

### 2.4 全社サマリー

複数施設を持つ利用者には、ドロップダウン最上段に**「全社サマリー」**を置きます。

| 条件 | 動作 |
|---|---|
| 単一施設の利用者 | 全社サマリーを表示しない |
| 複数施設の利用者 | 既定表示を全社サマリーとする |
| 全社表示中 | 施設名の見出しで区切って表示 |
| 全社表示中 | 全社表示であることを画面内に明示 |

## 3. 通知とユーザー領域

### 3.1 配置

topbar 右端に、**通知 → ユーザー**の順で配置します。

### 3.2 通知バッジ

| 規定 | 内容 |
|---|---|
| 件数に含める | 重要度 HIGH・MEDIUM |
| 件数に含めない | 重要度 LOW |
| 99件超 | 「99+」と表示 |
| 0件 | バッジを表示しない |

### 3.3 ユーザーメニュー

役割と閲覧範囲を**バッジで必ず表示**します。v3標準の必須項目です。

| 役割 | バッジ表記 |
|---|---|
| オーナー | オーナー · 自施設のみ |
| 運営管理者 | 運営管理者 · 全施設 |
| 現場責任者 | 現場責任者 · 担当施設 |
| プラットフォーム運営 | プラットフォーム運営 · 全テナント |

メニュー項目は以下に固定します。

- アカウント設定
- 通知の設定
- 言語（現在の言語を併記）
- ヘルプ
- ログアウト（`--danger` 色）

### 3.4 言語切替の配置

| 画面 | 配置 |
|---|---|
| 管理PC ログイン前 | 横並びボタン |
| 管理PC ログイン後 | **ユーザーメニュー内**（topbarに常設しない） |

ログイン前はユーザーメニューが存在しないため横並びとします。これは本標準の例外です。

## 4. サイドバー

### 4.1 含めるもの

ナビゲーションのみです。

- セクション見出し
- ナビゲーション項目（アイコン + ラベル + 件数バッジ）
- フッターの権限注記

### 4.2 含めないもの

| 要素 | 正しい配置 |
|---|---|
| ブランドロゴ | topbar 左 |
| 施設セレクタ | topbar 左（ブランドの右隣） |
| ユーザー情報 | topbar 右端 |
| 通知 | topbar 右端 |

### 4.3 フッター注記

サイドバー最下部に閲覧範囲の注記を置きます。オーナー向けの場合は以下の2行です。

```
閲覧権限：自施設のみ
清掃員の氏名は非表示
```

### 4.4 折りたたみ（第2版で追加）

サイドバーは利用者の操作で**レール状態（56px）**に折りたためます。

| 規定 | 内容 |
|---|---|
| レール時の表示 | アイコンのみ。ラベル・件数バッジ・フッター注記は隠す |
| レール時の補助 | 各項目に `title`（ラベル全文）を付ける |
| 現在地と locked | レール時もアイコンの状態表示で判別できること |
| トグルの位置 | サイドバー最下部 |
| 状態の保持 | サーバー側（セッション）に持つ。初回描画から確定した幅で描く（ちらつき禁止） |
| ブランド領域 | サイドバー幅に**常に同期**させる（§1.1） |

セクション見出しはクリックで開閉できます（既定は全展開）。開閉の選択は端末に保持してよいですが、サーバー描画は常に全展開とし、閉じる方向にだけ後から反映します。

**HTML プロトタイプ（`ui-prototypes/`）に折りたたみは存在しません。** 本節が折りたたみの正であり、PROTOTYPE_GAP.md の「プロトタイプに無いものは出さない」原則の明示的な例外です（オーナー指示 2026-08-19 / P7-21）。
